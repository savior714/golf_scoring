# 🏌️ 골프장 데이터 준비 방법 — GET_COURSE 가이드

> 최초 작성: 2026-03-12 | 목적: `admin_import.tsx` JSON Bulk Import 화면에 붙여넣을 구장 데이터를 구하고 만드는 방법 안내

---

## 앱이 요구하는 JSON 구조 (핵심)

```json
[
  {
    "name": "○○ 컨트리클럽",
    "address": "경기도 용인시 ...",
    "courses": [
      {
        "name": "OUT",
        "holes": [
          {
            "holeNumber": 1,
            "par": 4,
            "distances": [
              { "teeColor": "Black", "distanceMeter": 380 },
              { "teeColor": "Blue",  "distanceMeter": 360 },
              { "teeColor": "White", "distanceMeter": 330 },
              { "teeColor": "Red",   "distanceMeter": 290 }
            ]
          }
          // ... 홀 2~9까지, 총 9홀
        ]
      },
      {
        "name": "IN",
        "holes": [
          // ... 마찬가지로 9홀
        ]
      }
    ]
  }
]
```

### ⚠️ 검증 규칙 (이걸 어기면 앱 등록 불가)

| 규칙       | 내용                                       |
| ---------- | ------------------------------------------ |
| 홀 수      | 코스당 **정확히 9홀**                      |
| 파 합계    | 9홀의 par 합계 **= 정확히 36**             |
| 티 거리    | 각 홀에 **최소 1개 이상** 필수             |
| 거리 값    | **양의 정수만 허용** (0 불가)              |
| 코스 단위  | 18홀 → OUT/IN 2개, 27홀 → 3개 코스        |

---

## 📋 실전 데이터 입력 방법 3가지

### ✅ 방법 A: ChatGPT / Claude에게 요청 (가장 추천)

아래 프롬프트를 복사해서 ChatGPT나 Claude에 붙여넣으세요:

```text
아래 JSON 형식에 맞게 "[○○ 컨트리클럽]" 골프장 데이터를 만들어줘.

규칙:
- courses 배열: 9홀 단위로 코스를 분리 (18홀이면 OUT/IN 2개, 27홀이면 3개)
- 각 코스는 holes 9개, par 합계 반드시 36
- teeColor는 "Black", "Blue", "White", "Red" 중 사용
- distanceMeter는 실제 거리(미터) 정수값

형식:
[{ "name": "구장명", "address": "주소", "courses": [{ "name": "OUT", "holes": [{ "holeNumber": 1, "par": 4, "distances": [{ "teeColor": "White", "distanceMeter": 320 }] }] }] }]
```

> **참고**: 유명 골프장(남촌CC, 레이크사이드CC 등)은 ChatGPT가 파/거리 정보를 이미 알고 있어 JSON을 바로 뽑아줍니다.  
> 정확도가 중요하다면 공식 홈페이지와 교차 검증하세요.

---

### ✅ 방법 B: 골프장 공식 홈페이지 / 스코어카드 참고

1. 해당 골프장 공식 홈페이지 → **코스 소개** 메뉴 진입
2. 각 홀의 **파(Par)** 와 **거리** 확인
   - 야드(yd) 단위라면 `× 0.9144` 로 **미터(m)** 변환
3. 위 JSON 형식에 맞게 직접 입력

---

### ✅ 방법 C: 앱 내 "샘플 불러오기" 후 수정

1. 앱의 **대량 데이터 임포트** 화면 진입
2. **"샘플 불러오기"** 버튼 탭
3. 텍스트 박스에 나타난 JSON을 **복사**
4. 메모장 또는 VSCode에서 구장명/주소/파/거리 값을 실제 정보로 교체
5. 수정된 JSON을 다시 앱에 **붙여넣기**

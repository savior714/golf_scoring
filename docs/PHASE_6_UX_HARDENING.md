# Phase 6: 세련된 UX 및 시스템 모니터링 강화 계획 (2026-03-10)

본 문서는 **Phase 5(시스템 안정화)** 이후의 후속 공정으로, 사용자에게 시각적으로 세련된 피드백을 제공하고 앱의 성능 및 안정성을 실시간으로 파악하기 위한 전략을 담고 있습니다.

## 1. 개요 (Overview)

- **목표**: 둔탁한 알림창(Alert.alert)을 세련된 **토스트(Toast) 시스템**으로 전면 교체하고, 앱 내 주요 지표를 모니터링할 수 있는 **관측성(Observability)** 확보.
- **철학**: 사용자의 입력을 방해하지 않는 비침습적 피드백과 지표 기반의 성능 최적화.

---

## 2. 세부 실행 단계 (Phases)

### Phase 1: 비침습적 피드백 시스템 (Interactive Feedback) - [DONE]

- **Task 1.1: react-native-toast-message 도입 및 커스터마이징** [DONE]
  - 골프 앱 테마(Navy/Green)에 맞춘 커스텀 토스트 레이아웃 설계 완료.
- **Task 1.2: 기존 Alert 로직 전면 마이그레이션** [DONE]
  - `saveCurrentHole`, `pullRounds`, `deleteRound` 등의 피드백을 토스트로 교체 완료.
- **Task 1.3: 햅틱(Haptic) 피드백 연동** [DONE]
  - 점수 조작 및 주요 성공/실패 액션에 진동 반응 추가 완료.

### Phase 2: 성능 최적화 및 모니터링 (Performance & Observability)

- **Task 2.1: React Query DevTools 및 프로파일링**
  - 데이터 페칭 워크플로우 분석을 통해 불필요한 리렌더링 및 API 호출 제거.
  - useMemo, useCallback 정밀 검토 및 불필요한 객체 생성 방지.
- **Task 2.2: 커스텀 로깅 가이드라인 수립**
  - [DEBUG], [INFO], [WARN], [ERROR] 접두사를 활용한 터미널 로그 가독성 개선.
  - 치명적 에러 발생 시 사용자 기기 정보 및 상태 스택을 보존하는 메커니즘 검토.
- **Task 2.3: 오프라인 큐 처리 효율성 강화**
  - 저전력/불안정한 네트워크 환경에서의 재시도 전략(Exponential Backoff) 고도화.

### Phase 3: 마이크로 애니메이션 및 레이아웃 폴리싱 (Micro-Animations)

- **Task 3.1: 레이아웃 트랜지션 적용**
  - 홀 전환(currentHole 변경) 시 슬라이드 또는 페이드 효과 적용.
  - Moti 또는 Reanimated 라이브러리를 활용한 부드러운 UI 반응성 확보.
- **Task 3.2: 스코어카드(Scorecard) 인터랙티브 개선**
  - 카드 내 특정 홀 터치 시 즉시 해당 홀 기록 화면으로 이동하는 딥링크 강화.

---

## 3. 기대 효과 (Expected Outcomes)

1. **사용자 경험 향상**: 단순 기록 앱을 넘어, 시각적/촉각적 피드백이 살아있는 프리미엄 앱으로 진화.
2. **기술적 부채 해결**: Any 타입 박멸 및 함수형 업데이트 표준화를 통한 유지보수 비용 절감.
3. **안정성 증대**: 모니터링 체계를 통해 실제 운영 환경에서의 버그 감지 속도 개선.

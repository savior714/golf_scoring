# Golf Scoring Application - Improvement Plan (향후 개선 계획)

**이 문서는 프로젝트의 기능 고도화, 사용자 경험 개선, 그리고 기술적 안정성을 강화하기 위한 단계별 실행 계획을 담고 있습니다.** 모든 단계는 작고 독립적인 기능 단위로 설계되었습니다.

---

## Phase 1: Analytics & Insight (통계 및 데이터 시각화)

### 1.1. 상세 통계 엔진 고도화

- [x] **Step 1.1.1: 통계 서비스 확장** - `golf.service.ts` 내에 `calculateAdvancedStats` (평균 퍼트, GIR, FIR 상세 추이) 로직 추가.
- [x] **Step 1.1.2: 최근 5경기 추세선** - 대시보드에 스코어 및 퍼트 수 변화를 보여주는 작은 라인 차트 컴포넌트 추가.

### 1.2. 미스 샷 패턴 시각화

- [x] **Step 1.2.1: 패턴 히트맵** - 가장 빈번한 미스 샷(슬라이스, 훅 등)을 대시보드에 강조 표시.
- [x] **Step 1.2.2: 상황별 분석** - 파3(아이언) vs 파4/5(드라이버) 간의 미스 패턴 분리 통계 제공.

## Phase 2: Social & Sharing (사회적 기능 및 기록 공유)

- [x] **Step 2.1.2: 디자인 템플릿** - 인스타그램/카카오톡 공유용 세로형 스코어카드 레이아웃 제작.
- [x] **Step 2.1.3: 공유 API 연동** - `expo-sharing`을 이용한 이미지 외부 앱 전송 기능 추가.
